# 🚗 Vehicle Rental Management Portal

A dynamic, multi-tier web application designed to automate the operational workflow of a vehicle leasing agency. This project features a responsive frontend interface powered by **HTML5/CSS3/JavaScript (Fetch API)**, a robust server middleware managed via **Python (Flask Framework)**, and an enterprise-grade backend infrastructure utilizing **Oracle PL/SQL (Stored Procedures and Triggers)**.

## 🎯 Project Objectives
- **Automate Fleet Control:** Move manual record-keeping to a central, high-integrity database.
- **Prevent Multi-Allocations:** Implement real-time vehicle state evaluation (`AVAILABLE` / `RENTED`) to enforce zero double-booking rules.
- **Database Level Computation:** Offload core financial math from the application code to high-performance database blocks.
- **Seamless System Sync:** Establish a live asynchronous connection framework between the browser interface and relational data.

---

## ✨ Features
- **🔒 Administrative Access Gateway:** Secured system perimeter using custom credential authentication matching your designated system access profile.
- **🚘 Responsive Fleet Live Board:** Real-time visibility of a 5-vehicle garage split dynamically into Category components (Cars and Bikes).
- **⚙️ PL/SQL Stored Procedure Control:** All scheduling, status switching, and database insertion rules are processed directly by the database engine.
- **⚡ Autonomous Schema Triggers:** An event-driven trigger monitors lease terms; reservations exceeding 7 days receive an instantaneous 10% cash discount.
- **📅 Future Returns Calendar:** Dynamically projects exact calendar dates (`Return Date`) when the vehicle is due back at the garage.

## 🏗️ System Architecture Flow
1. **Presentation Layer (Frontend):** The admin interacts with an interactive interface, selecting items and setting parameters.
2. **Application Layer (Middleware):** The Flask server maps incoming JSON requests and prepares them for database transfer.
3. **Database Access Layer (PL/SQL Pipeline):** The server triggers the database engine, calling the pre-compiled Stored Procedure.
4. **Data Integrity Layer (Oracle DB):** The database calculates costs via Triggers, safely updates rows, and returns a verified data payload to the web layout.

## 🗄️ Database Table Structures

### 1. `rent_vehicles` (Garage Catalog)
- `vehicle_id` (VARCHAR2) - Primary Key tracking unique vehicle assets.
- `model_name` (VARCHAR2) - Visual descriptor of the car/bike models.
- `rent_per_day` (NUMBER) - Price matrices used for base calculations.
- `status` (VARCHAR2) - Operational conditional toggle (`AVAILABLE` / `RENTED`).

### 2. `rent_bookings` (Reservation Logs)
- `booking_id` (NUMBER) - Identity autogenerated primary reference keys.
- `customer_name` (VARCHAR2) - Complete name index of the leasing user.
- `days_rented` (NUMBER) - Duration metric evaluated by triggers.
- `total_bill` (NUMBER) - Verified cost payload generated at schema levels.
- `booking_date` / `return_date` (DATE) - Temporal tracking indicators.

## 🚀 Local Installation & Setup

1. **Clone the Repo:** Download these repository assets onto your local workstation.
2. **Oracle Database Configuration:**
   - Execute the schema structural logs available in `Code.txt` using your database connection window.
   - Compile the Stored Procedure and Database Trigger rules securely into your schema profile.
3. **Configure Connection Properties:**
   - Open `app.py` and align the environment values (`DB_USER`, `DB_PASSWORD`, `DB_DSN`) to match your Oracle host configuration.
4. **Deploy the System:**
   - Open Command Prompt (CMD) in the root directory.
   - Run dependency allocations and fire up the server:
     ```bash
     pip install flask oracledb
     python app.py
     ```
5. **Access the Portal:** Launch any web browser and open: `http://127.0.0`
